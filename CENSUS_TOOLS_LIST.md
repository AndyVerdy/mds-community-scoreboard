# Census "Tools & providers" list — sourced from the GroupOS partner directory

**Why this doc:** Eugene flagged the census tool questions (Q14–15) as outdated ("archetype changed"). Instead of guessing, we ranked the **GroupOS partner directory** by real member engagement and derived the service categories + leading providers from it. This is the drop-in replacement list for the census Tools question.

## Source data
4 CSV exports Andy pulled from the GroupOS admin partner table (`/Users/Born/Downloads/partners*.csv`), 2026-07-29. They are **2 sorts × 2 pages**, not 4 separate lists:
- **Views-ranked** top ~100 = `partners (2).csv` (378→47) + `partners (3).csv` (47→20)
- **Claims-ranked** top ~100 = `partners (1).csv` (258→21) + `partners.csv` (19→8)
- Every row carries **Views / Reviews / Rating / Claims**, so the **Reviews** ranking is derived from the same rows — no separate export needed.

**Signal meaning:** *Claims* = members who clicked "Get Offer" (intent/adoption) · *Reviews* = members who used it and rated (real usage) · *Views* = interest. Ranking below is by **Claims** (adoption), with Reviews shown as the usage cross-check.
